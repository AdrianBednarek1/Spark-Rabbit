# Spark Rabbit - 2D platformer game
Spark Rabbit is a 2D platformer game made in Unity. It contains 2 levels including a boss fight. The main character is the rabbit called Spark and the goal of the game is to complete the level by crossing the end point.

Functionalities:
- UI
- 4 types of enemies with 4 different patrols
- player movement, combat, special movement
- life and hp system
- music system
- items and point counter
- game over and victory
